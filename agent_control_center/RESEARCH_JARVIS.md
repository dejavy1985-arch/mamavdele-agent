# Jarvis и Клоп: полный перечень функций и статусы

Источник: исходный код `coreybain/jarvis` (коммит `6ee5684`, лицензия Apache-2.0),
а не только README. Каждая функция ниже найдена в коде (роутеры `src/main/lib/trpc`,
модули `src/main/lib`, экраны `src/renderer/features`).

Клоп это собственный Jarvis владелицы для всех её проектов: приложение на компьютере
с Windows, управление из Telegram с телефона и работа на сервере, когда компьютер
выключен. Полный набор функций Jarvis это цель проекта, ни одна функция не исключена.
Порядок добавления решает владелица.

## Обозначения

- ✅ **полностью**: реализовано в Клопе и проверено автотестами;
- 🟡 **частично**: часть сделана и проверена, чего не хватает, написано рядом;
- ❌ **отсутствует**: пока не сделано;
- 🔒 **без внешнего сервиса невозможна**: функции нужен сервер с публичным адресом,
  API-ключ стороннего сервиса или платный сервис (какой именно, указано).

Что означает каждый столбец: «Клоп» это статус; «Что есть и чего нет» говорит, что
уже работает и что требует разработки; «Нужно извне» называет внешний сервис, ключ
или сервер, без которого функцию не сделать.

«Проверено» значит автотестами: Linux (Python 3.10 до 3.13) и Windows 10 (Python
3.13, 147 тестов, 7 пропущены, потому что требуют песочницу Linux). Живой Telegram
ещё не проверялся: нужен токен нового бота.

## Что нужно извне (сводно)

**Beget (VPS, а не виртуальный хостинг):** работа без вашего компьютера, песочница
bubblewrap, фоновые агенты. Публичный HTTPS-адрес на нём нужен для: десктоп- и
веб-приложения не с этого компьютера, превью сайтов, вебхуков GitHub, Linear, Slack,
программного API.

**API-ключи:** Anthropic (Claude Code), OpenAI (Codex, голос Whisper), GitHub (push,
PR, статусы, Git-триггеры), Linear и Slack (их триггеры), токен Telegram-бота
(бесплатно).

**Платно:** Beget VPS (тариф хостинга), Claude по API (оплата за использование) или
подписка Claude, OpenAI по использованию. Подписка Jarvis не нужна ни для одной
функции. PostHog и Sentry по желанию, у них есть бесплатные тарифы.

**Бесплатно и локально:** всё остальное; локальные модели через Ollama бесплатны,
но требуют мощного сервера.

## Порядок работ (решения владелицы от 29.09.2026)

Решено: Клоп отдельный проект со своим репозиторием; работает на компьютере с
Windows (приложение), из Telegram с телефона и на сервере при выключенном
компьютере; пользуется им только владелица; агентам не выдаются ключи для
публикаций, переписки с клиентами и платежей. Не решено: API или подписка
(`ACCESS_AND_COSTS.md`), сервер (тариф Beget не известен), первый подключаемый
проект.

Номера в скобках это пункты таблицы. Каждый шаг проверяется тестами, сначала на
тестовом агенте; действующие агенты не затрагиваются.

**Можно делать сейчас, без сервера и без доступа к проектам:**

1. **Отдельный репозиторий** с полной историей Клопа, пути в скриптах под новый
   адрес. PR #1 в mamavdele-agent не сливается и не закрывается, пока не проверено,
   что перенос полный.
2. **Windows как рабочая платформа** (66, 16): все тесты на Windows (сделано),
   адаптер Claude Code на `claude.exe`, изоляция домиков через WSL2 с bubblewrap
   или отдельного пользователя Windows, автозапуск.
3. **Прогресс, уведомления, прозрачность** (19, 20, 21, 37, 38, 44): шаги агента,
   подзадачи и расход видны во время работы, одно сообщение обновляется.
4. **Диалог с агентом и контроль** (12, 13, 14): Plan Mode, уточняющие вопросы
   агента в чате, подтверждение отдельных шагов кнопками.
5. **Десктоп-приложение на Windows и канбан** (33, 34, 45, 46, 39, 43): окно с
   проектами, очередью, историей и доской задач на том же ядре, что Telegram.
6. **Файлы и фото** (36, 52, 40): вложения из чата в папку домика, файлы
   результата обратно, экспорт.
7. **Шлюз подтверждаемых действий** (15, 48): агент предлагает действие,
   владелица подтверждает, выполняет отдельный процесс, который один хранит ключи
   (раздел 7).

**После выбора способа оплаты (API или подписка):**

8. **Живой Claude Code на Windows и первый реальный проект** (2, 4, 11, 22, 23).
9. **Модели и движки** (3, 25, 26, 27, 28): Codex вторым движком, выбор модели из
   чата, локальные модели.
10. **Навыки, субагенты, MCP, плагины** (23, 24, 29, 30, 31).

**После появления сервера:**

## 7. Требования владелицы сверх Jarvis

| Что | Статус | Что есть и чего нет |
| --- | --- | --- |
| Отдельный репозиторий Клопа | 🟡 | История выделена и проверена локально, новый репозиторий ждёт решения о названии |
| Запрет публикаций, переписки с клиентами и платежей доступами | 🟡 | Ключей таких сервисов у агентов нет. Автоматической проверки, что в `secrets/agent.env` домика не попали такие ключи, пока нет |
| Шлюз «предложил, подтвердила, выполнено» | ❌ | План: агент пишет предложение действия в свою папку; Клоп показывает его в Telegram и в приложении с кнопками; только отдельный процесс шлюза хранит ключи сервиса и выполняет действие после подтверждения; всё пишется в журнал |
| Windows обязательна | 🟡 | См. пп. 16 и 66 |
| Работа при выключенном компьютере | 🔒 | Нужен VPS |
