# Jarvis и Клоп: полный перечень функций и статусы

Источник: исходный код `coreybain/jarvis` (коммит `6ee5684`, лицензия Apache-2.0),
а не только README. Каждая функция ниже найдена в коде (роутеры `src/main/lib/trpc`,
модули `src/main/lib`, экраны `src/renderer/features`).

Клоп это Jarvis, перенесённый в единый Telegram-чат. Ни одна функция не исключена:
что добавлять и в каком порядке, решает владелица. Здесь только факты.

## Обозначения

- ✅ **полностью**: реализовано в Клопе и проверено автотестами;
- 🟡 **частично**: часть сделана и проверена, чего не хватает, написано рядом;
- ❌ **отсутствует**: пока не сделано;
- 🔒 **без внешнего сервиса невозможна**: функции нужен сервер с публичным адресом,
  API-ключ стороннего сервиса или платный сервис (какой именно, указано).

«Проверено» значит автотестами в этой среде (Linux, Python 3.10, 3.11, 3.12, 3.13).
Живой Telegram и живой Claude Code ещё не проверялись: для этого нужны токен бота и
ключ Anthropic на вашем сервере.

## Что нужно извне (сводно)

**Beget (VPS, а не виртуальный хостинг):** работа без вашего компьютера, песочница
bubblewrap, фоновые агенты. Публичный HTTPS-адрес на нём нужен для: десктоп- и
веб-приложения не с этого компьютера, превью сайтов, вебхуков GitHub, Linear, Slack,
программного API.

**API-ключи:** Anthropic (Claude Code), OpenAI (Codex, голос Whisper), GitHub (push,
PR, статусы, Git-триггеры), Linear и Slack (их триггеры), токен Telegram-бота
(бесплатно).

**Платно:** Beget VPS (тариф хостинга), Claude по API (оплата за использование) или
подписка Claude, OpenAI по использованию. Подписка Jarvis не нужна ни для одной
функции. PostHog и Sentry по желанию, у них есть бесплатные тарифы.

**Бесплатно и локально:** всё остальное; локальные модели через Ollama бесплатны,
но требуют мощного сервера.

## Предлагаемый порядок добавления (решение за вами)

Номера в скобках это пункты таблицы выше. Каждый шаг проверяется тестами и
сначала на тестовом агенте, действующие агенты не затрагиваются.

1. **Запуск на сервере и первый живой агент** (2, 4, 5, 11, 22, 64): Beget VPS, bubblewrap,
   Claude Code, токен бота; вы выбираете первый реальный проект, он подключается
   адаптером `claude_code`. Нужно: VPS, ключ Anthropic, токен бота.
2. **Прогресс, уведомления, прозрачность** (19, 20, 21, 37, 38, 44): шаги агента, подзадачи и расход
   видны во время работы, одно сообщение обновляется.
3. **Диалог с агентом и контроль** (12, 13, 14): Plan Mode (план, затем выполнение
   по команде), уточняющие вопросы агента в чате, подтверждение отдельных шагов
   кнопками Telegram.
4. **Файлы, фото и голос** (35, 36, 52): вложения из чата в папку домика, файлы
   результата обратно, голосовые сообщения. Для голоса нужен ключ OpenAI или мощный VPS.
5. **Канбан и приложение** (33, 34, 45, 46, 32): доска задач, установка как
   десктоп-приложение, доступ с телефона вне Telegram. Для доступа не с этого
   компьютера нужен HTTPS-адрес на сервере.
6. **Git в домиках** (17, 18, 47, 49, 50, 51, 48, 55): ветка на задачу, диффы, откат,
   коммит; push и PR только после подтверждения; новый домик из репозитория
   (аналог импорта песочницы Jarvis). Нужен токен GitHub.
7. **Модели и движки** (3, 25, 26, 27, 28): выбор модели из чата, Codex вторым
   движком, локальные модели. Нужны ключ OpenAI или мощный VPS.
8. **Навыки, субагенты, MCP, плагины** (23, 24, 29, 30, 31): подключение и
   управление на уровне домика.
9. **Автоматизации** (59, 56, 57, 58): расписание, затем триггеры GitHub, Linear,
   Slack с условиями и таймлайном. Нужны HTTPS-адрес и токены сервисов.
10. **Работа с историей** (39, 40, 41, 42, 43): поиск, экспорт, черновики задач, форк, архив.
11. **API и превью** (60, 54): запуск задач запросом, dev-превью по ссылке.
    Нужен HTTPS-адрес.
12. **Служебное** (53, 62, 63, 65, 66): терминал с ограничениями, мастер настройки,
    автообновление, аналитика, проверка на Windows.
