# Пробный запуск Клопа на Beget

Цель: проверить Клопа на настоящем сервере с настоящим Claude Code и настоящим
Telegram-ботом. Работает только тестовый домик `trial-claude`. Рабочие агенты не
подключаются и не запускаются.

## 1. Как узнать свой тариф в кабинете Beget

1. Откройте cp.beget.com и войдите своим логином и паролем.
2. Посмотрите на меню панели:
   - есть раздел «Облако» (может называться «VPS» или «Облачные серверы»), и в нём
     ваш сервер с IP-адресом: у вас **VPS**, он подходит;
   - сервера там нет, а в разделе «Хостинг» указан тариф: у вас **виртуальный
     хостинг**, для Клопа он не подходит.
3. Ещё один признак виртуального хостинга: адрес сайта вида `логин.beget.tech`. У
   действующего агента адрес именно такой.
4. Если сомневаетесь, пришлите снимок экрана главной страницы панели. На снимке не
   должно быть паролей.

Названия разделов я взял из справки и обзоров Beget, саму панель я не видел. Если
они отличаются, ищите раздел со списком серверов.

## 2. Что потребуется

| Что | Где взять | Платно |
| --- | --- | --- |
| VPS на Beget: **локация Рига**, Ubuntu 24.04, 2 ядра, 4 ГБ памяти, диск от 30 ГБ | cp.beget.com, раздел «Облако», создать сервер | да, по тарифу Beget |
| IP-адрес сервера и пароль root | Beget показывает их при создании сервера или присылает письмом | нет |
| Программа для входа на сервер | в Windows 10 и 11 уже есть: откройте «Терминал» и наберите `ssh` | нет |
| Доступ к Claude: ключ API **или** подписка Claude Pro/Max | ключ: platform.claude.com, раздел API keys, баланс от 5 долларов; подписка: команда `claude setup-token` на сервере | да |
| Новый бот Telegram | @BotFather, команда /newbot | нет |
| Ваш user_id в Telegram | скрипт `setup_secrets.sh` покажет его сам | нет |
| Время | около 30 минут | |

Почему Рига: Anthropic не обслуживает запросы из России, с сервера в России Claude
Code работать не будет. Латвия в списке поддерживаемых стран есть.

Стоимость пробного запуска: 4 задачи Claude Code. При проверке в облаке задача
стоила от 4 до 9 центов, лимит на одну задачу 0,5 доллара.

Бот действующего агента не подходит, нужен новый. Если по ошибке ввести токен
действующего бота, Клоп заметит, что его сообщения уже получает другой сервис, и
откажется работать с этим ботом, ничего в нём не меняя.

## 3. Шаги

1. **Создайте VPS** в панели Beget: локация Рига, Ubuntu 24.04, 2 ядра, 4 ГБ, 30 ГБ.
   Запишите IP-адрес и пароль root. Никому их не пересылайте.
2. **Войдите на сервер.** В «Терминале» Windows наберите (вместо IP ваш адрес):
   ```
   ssh root@IP
   ```
   На вопрос про fingerprint ответьте `yes`, затем введите пароль root. Пароль при
   вводе не отображается, так и задумано.
3. **Установите Клопа** одной командой (скопируйте целиком):
   ```
   curl -fsSL https://raw.githubusercontent.com/dejavy1985-arch/mamavdele-agent/refs/heads/claude/agent-control-center-telegram-c92k4k/agent_control_center/scripts/install_server.sh -o install_server.sh && bash install_server.sh
   ```
   Скрипт ставит нужные программы, создаёт пользователя `klop` без прав
   администратора, скачивает только папку Клопа и ставит Claude Code. Службу он не
   включает.
4. **Введите ключи.** Ввод скрытый, ключи остаются только на сервере:
   ```
   su - klop
   cd ~/klop/agent_control_center
   bash scripts/setup_secrets.sh
   ```
   Скрипт попросит ключ Claude, токен нового бота и ваш user_id, который он
   покажет, когда вы напишете боту.
5. **Запустите проверку:**
   ```
   python3 -m acc.cli trial --telegram
   ```
   Когда бот напишет «🧪 Клоп на сервере: пробный запуск», отправьте ему:
   `проба: придумай три названия для кофейни`. Бот ждёт 10 минут.
6. **Пришлите отчёт.** Покажите его командой:
   ```
   cat var/trial_report.md
   ```
   Скопируйте текст в чат со мной. В отчёте нет ключей и токенов.

## 4. Что будет в отчёте

- **Что выполнилось на сервере:** система, память, диск, песочница, Claude Code,
  связь с Claude и Telegram, автотесты. Изоляция: пробный агент не видит соседние
  папки, базу задач, токен бота и чужие ключи. Три настоящие задачи Claude Code:
  создать файл, продолжить разговор, открыть сайт.
- **Что пришло в Telegram:** ваше сообщение, ответ «Принято», результат агента
  ответом на ваше сообщение, доставлено ли каждое сообщение.
- **Ограничения, которые остаются,** и итог: пройдено, пройдено с замечаниями или
  не пройдено, с пунктами для исправления.

## 5. После проверки

- Если всё прошло, решение о слиянии PR за вами. Постоянную работу включают
  командой от root: `systemctl enable --now acc`.
- Первый рабочий проект подключается отдельным шагом, после вашего решения.
- Повторная проверка: снова `python3 -m acc.cli trial --telegram`. Без Telegram:
  `python3 -m acc.cli trial`.
