# Доступ к моделям для Клопа: API или подписка

Документ для решения владелицы. Сумму бюджета здесь никто не выбирал и не
предлагает: только факты из официальных источников на 29.09.2026 и замеры Клопа.
Цены меняются, перед решением их стоит сверить по ссылкам в конце.

## Коротко

| | Claude Code | Codex |
| --- | --- | --- |
| Оплата по API | ключ из platform.claude.com, оплата за токены | ключ из platform.openai.com, оплата за токены |
| Подписка | Pro, Max 5x, Max 20x | планы ChatGPT (Free, Go, Plus, Pro, Business) |
| Лимит по API | лимит расходов рабочего пространства в консоли, `--max-budget-usd` на задачу | лимиты уровня аккаунта (tier) и бюджет в консоли |
| Лимит по подписке | окно 5 часов и недельный лимит, общий с чатом Claude | окно 5 часов, возможен недельный лимит, общий с облачным Codex |
| Вход без браузера | ключ `ANTHROPIC_API_KEY` или токен `claude setup-token` на год | ключ `CODEX_API_KEY` для `codex exec` или вход по коду `codex login --device-auth` |
| Что производитель советует для скриптов | ключ API; токен подписки допустим для своих скриптов | ключ API для CI и автоматизации |
| Песочница на Windows без WSL | нет | есть (своя, запрещает запись вне рабочей папки) |
| Песочница в WSL2 и Linux | есть | есть (bubblewrap) |

## Claude Code

**Подписка.** Pro, Max 5x за 100 долларов в месяц, Max 20x за 200 долларов в месяц
(по справке Anthropic). Цену Pro сверьте на claude.com/pricing: страница показывает
20 долларов в месяц или 17 при оплате за год. Лимит считается окнами по 5 часов, есть
недельный лимит на все модели, и Anthropic оставляет за собой право вводить другие
ограничения. После лимита можно включить платные «usage credits» по ценам API.

**Можно ли Клопу работать от подписки.** Правила Anthropic разрешают входить своей
подпиской в неизменённый Claude Code, в том числе когда его запускает чужая
платформа, и прямо называют `claude setup-token` способом для скриптов и CI. Клоп
запускает именно официальный `claude`, поэтому для одной владелицы это допустимо.
Ограничения, которые остаются:

- лимиты подписки рассчитаны на «обычное индивидуальное использование»; много
  фоновых агентов подряд быстро выберут окно в 5 часов, а Anthropic вправе
  ограничить нетипичную нагрузку;
- токен `setup-token` умеет только запросы к модели: без Remote Control и без
  коннекторов claude.ai;
- с флагом `--bare` токен подписки не читается, нужен ключ API;
- Клопу нельзя собирать или хранить чужие учётные данные Claude: только ваш токен
  на вашем сервере;
- если в окружении есть и ключ API, и токен подписки, Claude Code возьмёт ключ API.

**API.** Цены за миллион токенов (вход / выход): Haiku 4.5 1 / 5 долларов,
Sonnet 5.5 2 / 10, Opus 5.5 4 / 20, Fable 5.1 10 / 50. Кэш подсказок дешевле.
Лимит расходов задаётся в консоли на рабочее пространство, у Клопа дополнительно
`max_budget_usd` на задачу. По данным Anthropic, у компаний в среднем около 13
долларов на разработчика в активный день; это ориентир для постоянной работы с
кодом, а не для Клопа.

**Замер Клопа.** При проверке на настоящем Claude Code в облачной среде одна
короткая задача стоила от 4 до 9 центов. Выборка маленькая, для прогноза месяца
её мало.

**Windows.** Claude Code работает на Windows 10 1809+ напрямую или в WSL2. Своей
песочницы у Claude Code на Windows без WSL нет, в WSL2 есть. Для Клопа это значит:
изоляция домиков на Windows возможна через WSL2 с bubblewrap (как на сервере) или
через отдельных пользователей Windows на каждый домик. Сейчас не сделано ни то, ни
другое.

**Удалённый запуск.** Для работы при выключенном компьютере нужен сервер (Beget VPS
в Риге или другой в поддерживаемой стране). Россия в список поддерживаемых
Anthropic стран не входит.

## Codex

**Подписка.** Codex входит во все планы ChatGPT. Лимиты по оценке OpenAI за окно
5 часов, локальные сообщения, модель GPT-6 Sol: Plus 15 до 150, Pro 5x 70 до 700,
Pro 20x 300 до 3000. Облачные задачи и локальные делят один лимит, возможен
недельный лимит. Цены планов ChatGPT официальная страница мне не отдала (ошибка
403); сторонние обзоры называют Plus 20 долларов, Pro 100 или 200 долларов в месяц.
Перед решением сверить на chatgpt.com/pricing.

**API.** Цены за миллион токенов (вход / выход): GPT-6 Luna 0,10 / 0,50,
GPT-6 Sol 2 / 10, GPT-6 Astra 10 / 50, GPT-5.3-Codex 1,75 / 14.

**Автоматизация.** OpenAI советует для скриптов и CI ключ API (`CODEX_API_KEY`
действует только в `codex exec`). Вход через ChatGPT на сервере без браузера делается
кодом устройства; токены хранятся в `auth.json`, его нужно беречь как пароль.
Токены доступа ChatGPT для «доверенных скриптов и частных CI» описаны для рабочих
пространств ChatGPT.

**Windows.** Codex работает на Windows напрямую со своей песочницей (режимы
elevated и unelevated) и в WSL2. Песочница Codex запрещает запись вне рабочей папки
и сеть без разрешения, но про запрет чтения чужих папок в документации не сказано.
Для правила «агент не видит файлы другого» её одной недостаточно.

## Что выбрать: вопросы для решения

1. Сколько задач в день вы ожидаете отдавать агентам и будут ли они работать
   параллельно. От этого зависит, хватит ли окна подписки.
2. Нужна ли предсказуемая сумма в месяц (подписка) или оплата только за сделанное
   (API с лимитом в консоли).
3. Нужен ли Codex с первого дня или вторым движком позже.

Технически Клоп поддерживает оба способа для Claude Code: `ANTHROPIC_API_KEY` или
`CLAUDE_CODE_OAUTH_TOKEN` в `secrets/agent.env` домика. Адаптера Codex пока нет.
