# Установка и запуск на Windows (без команд cp и export)

Центр управления это отдельный локальный проект. Он работает на Python из
стандартной поставки, сторонние библиотеки не нужны. Telegram на этом шаге НЕ
включаем и токен НЕ требуется.

## Шаг 1. Поставить Python (один раз)

1. Откройте https://www.python.org/downloads/windows/ и скачайте Python 3.10 или новее.
2. В установщике поставьте галочку «Add Python to PATH», затем «Install Now».

## Шаг 2. Положить проект в отдельную папку

Скопируйте папку `agent_control_center` в удобное место, например
`C:\Users\Вы\agent_control_center`. Это отдельный проект, он не связан с папкой
действующего агента и ничего в ней не меняет.

## Шаг 3. Установка и проверка (двойной клик)

1. Зайдите в папку `agent_control_center`, затем в папку `scripts`.
2. По файлу `setup_windows.ps1` нажмите правой кнопкой и выберите
   «Выполнить с помощью PowerShell».
3. Скрипт проверит Python, создаст рабочий конфиг, заведёт папки домиков и
   прогонит тесты. В конце должно быть «OK».

Если Windows не даёт запустить скрипт (политика выполнения), откройте PowerShell
и один раз выполните: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`,
подтвердите, затем повторите шаг.

## Шаг 4. Вписать свой Telegram user_id

1. Узнайте свой числовой user_id (например, у бота @userinfobot в Telegram).
2. Откройте файл `config\control_center.json` в «Блокноте».
3. В поле `allowed_user_ids` впишите своё число. Сохраните.

Это всё для текущего этапа. Проверить, что всё цело, можно повторным запуском
`scripts\run_tests_windows.ps1`.

## Что с секретами

Токен бота в GitHub не хранится. Когда позже включите Telegram, токен нужно будет
положить в файл `config\telegram_token.txt` одной строкой. Этот файл и рабочий
конфиг уже внесены в `.gitignore`, поэтому в репозиторий не попадут.

## Запуск Telegram (шаг на потом, не сейчас)

Когда решите включить бота, порядок описан в самом верху файла
`scripts\start_center_windows.ps1`. Пока его запускать не нужно.

## Автозапуск при включении компьютера (по желанию, позже)

Через «Планировщик заданий» Windows: создать задачу «При входе в систему», действие
«Запуск программы» -> `powershell.exe`, аргументы:
`-File "C:\...\agent_control_center\scripts\start_center_windows.ps1"`.
Так центр будет подниматься сам, пока компьютер включён. Настроим, когда дойдём.
