## Что это

Собственный Jarvis владелицы для всех её проектов. Задачи существующим агентам
даются из одного Telegram-чата и из приложения на компьютере с Windows. Клоп
направляет задачу в домик нужного проекта, агент выполняет её в своей папке,
Клоп показывает ход работы и возвращает результат. Работает и на сервере, когда
компьютер выключен. Полный набор функций Jarvis это цель проекта.

## Решения владелицы (29.09.2026)

1. Первые задачи: доработка кода агентов, подготовка контента агентом нужного
   проекта, исследование тем.
2. Клоп отдельный проект со своим репозиторием и историей. Действующего агента не
   затрагивать.
3. Нужны все три способа работы: приложение на Windows, Telegram с телефона,
   сервер при выключенном компьютере. Windows не является необязательной.
   Тариф Beget и доступ к серверу пока не известны.
4. Пользуется Клопом только владелица.
5. Бюджет и способ оплаты (API или подписка) не выбраны. Факты для выбора:
   `ACCESS_AND_COSTS.md`. Суммы не придумывать.
6. Запрет публикаций, переписки с клиентами и платежей держится доступами: агентам
   такие ключи не выдаются. Позже шлюз: агент предлагает действие, владелица
   подтверждает, только после этого оно выполняется.

## Правила владелицы (обязательны)

- Не менять действующего агента mamavdele-agent и файлы вне `agent_control_center/`.
- Один агент не видит файлы другого: техническая изоляция, не текст.
- Команды только от владелицы (allowlist по user_id).
- Клоп не публикует, не пишет клиентам, не платит, не меняет токены и доступы.
  Агентам не выдаются ключи для этого. Такие возможности только через шлюз с
  подтверждением и только по решению владелицы.
- Секреты не класть в git и не просить присылать в чат.
- Тестовые домики не называть подключёнными проектами.
- Не сокращать задачу: функции Jarvis не исключать без решения владелицы.
- Не придумывать бюджет, суммы и решения за владелицу.
- В текстах для владелицы без тире и без лести.

## Состояние

- Проверено на Linux (облачная среда): полный путь задачи из Telegram до ответа в
  тот же чат, очередь, отмена, восстановление после перезапуска, изоляция
  bubblewrap, настоящий Claude Code в песочнице.
- Проверено на Windows 10 (компьютер владелицы, Python 3.13): 147 тестов проходят,
  7 пропущены, потому что требуют песочницу Linux.
- Не сделано на Windows: изоляция домиков (нет bubblewrap; варианты WSL2 или
  отдельный пользователь Windows на домик), приложение, живой Claude Code.
- Не проверено: настоящий Telegram-бот, работа на сервере, служба systemd.
- Проверка запретных слов исправлена: «перевод текста» и «черновик публикации»
  больше не блокируются, «запость», «размести в ленте», «скинь в личку» ловятся.
