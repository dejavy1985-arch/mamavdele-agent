# Передача работы: Клоп (agent_control_center)

## Где лежит

- Репозиторий: github.com/dejavy1985-arch/mamavdele-agent
- Ветка: `claude/agent-control-center-telegram-c92k4k`
- PR: dejavy1985-arch/mamavdele-agent#1 (не слит, сливать только после проверки на сервере)
- Весь Клоп в папке `agent_control_center/`. Остальной репозиторий это действующий
  агент mamavdele-agent, его не трогать.

## Что это

Личный помощник с возможностями Jarvis в одном Telegram-чате. Задача из чата уходит
агенту нужного проекта, агент выполняет её в своей папке в песочнице, статус и
результат приходят ответом в тот же чат.

## Правила владельца (обязательны)

- Не менять действующего агента mamavdele-agent и файлы вне `agent_control_center/`.
- Один агент не видит файлы другого: техническая изоляция (bubblewrap), не текст.
- Команды только от владельца (allowlist по user_id).
- Клоп не публикует, не пишет клиентам, не платит, не меняет токены и доступы.
  Такие возможности без решения владельца не добавлять.
- Секреты не класть в git и не просить присылать в чат.
- Тестовые домики не называть подключёнными проектами.
- Не сокращать задачу: функции Jarvis не исключать без решения владельца.
- В текстах для владельца без тире и без лести.

## Карта файлов

| Что | Где |
| --- | --- |
| Ядро | `acc/`: `dispatcher.py` (доступ, границы, маршрут, очередь, команды), `worker.py` (выполнение и ответы в чат), `runner.py` (запуск агента, песочница, Claude Code), `telegram_bot.py`, `trial.py` (пробный запуск), `cli.py`, `store_db.py`, `router.py`, `guardrails.py`, `paths.py`, `registry.py` |
| Домики проектов | `homes/<id>/manifest.json`; `test-agent` и `trial-claude` тестовые; `mamavdele-agent` только заведён (`registered`) |
| Установка на сервер | `scripts/install_server.sh` (root), `scripts/setup_secrets.sh` (ключи), `deploy/acc.service` |
| Инструкции | `BEGET_TRIAL.md` (пробный запуск на Beget), `DEPLOY_SERVER.md`, `ADDING_PROJECTS.md`, `README.md`, `ARCHITECTURE.md` |
| Функции Jarvis | `RESEARCH_JARVIS.md`: 66 функций со статусами и порядок добавления из 12 шагов |
| Тесты | `tests/`, запуск `python3 tests/run_tests.py` (145 тестов, Python 3.10 до 3.13) |

## Состояние

- Готово и проверено: полный путь задачи из Telegram до ответа в тот же чат,
  очередь, отмена, восстановление после перезапуска, изоляция, настоящий Claude Code
  в песочнице (в облачной среде), защита от чужого бота (webhook) и от второго
  получателя сообщений.
- Не проверено: работа на Beget VPS, настоящий Telegram-бот, выход агента в
  интернет, профиль AppArmor на Ubuntu 24.04, служба systemd.
