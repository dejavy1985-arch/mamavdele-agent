# Как добавить проект (домик) без переписывания ядра

Ядро центра не нужно менять, чтобы подключить новый проект. Проект описывается
одним файлом `manifest.json` в своей папке внутри `homes/`. Реестр сам его находит,
маршрутизатор сам учитывает его ключевые слова, изоляция сама применяется к его папке.

## Вариант 1: командой (проще)

```
python -m acc.cli add-home my-project --title "Мой проект" --keywords "отчёт,выгрузка,клиенты" --aliases "мойпро"
```

Создаст `homes/my-project/` с манифестом (статус `registered`), папками `memory` и
`secrets`. Ядро не трогается.

## Вариант 2: вручную

Создайте `homes/<id>/manifest.json`:

```json
{
  "id": "my-project",
  "title": "Мой проект",
  "summary": "Короткое описание, чем занимается проект.",
  "status": "registered",
  "keywords": ["отчёт", "выгрузка", "клиенты"],
  "aliases": ["мойпро"],
  "adapter": { "type": "manual" },
  "allowed_actions": ["status", "route_task", "read_memory", "append_memory"]
}
```

Рядом создайте папки `memory/` и `secrets/` (в `secrets/` положите `.gitignore`
с содержимым `*` и `!.gitignore`, чтобы секреты не попали в git).

## Статусы домика

- `registered` домик заведён, но как живой агент ещё не подключён. Центр
  маршрутизирует к нему, но задачу не передаёт, а честно сообщает «не подключён».
- `connected` проект подключён и принимает поручения. Переводите в этот статус
  осознанно, когда агент проекта действительно готов принимать задачи.
- `not_connected` временно недоступен. `paused` выключен вручную.

Тестовые домики держите в статусе `registered`: это не подключённые проекты.

## Как маршрутизатор выбирает проект

По ключевым словам и псевдонимам из манифеста. Учитываются словоформы (по основе
слова), поэтому «картинка» находит «картинку». Советы для хорошего распознавания:

- ключевые слова давайте в базовой форме (единственное число): «отчёт», «клиент»;
- псевдонимы это короткие имена проекта, по которым вы его зовёте: «мойпро».

## Проверить, ничего не запуская

```
python -m acc.cli doctor                     # конфиг и домики валидны, изоляция цела
python -m acc.cli projects                   # список домиков и статусов
python -m acc.cli route "сделай выгрузку"     # какой проект выберется (без передачи)
python -m acc.cli demo                        # полный прогон на временных тест-проектах
```

Всё это работает без Telegram-токена и без доступа к действующим агентам.

## Подключить реального агента (позже)

Смена `manual` на `cross_session` в адаптере плюс `cross_session_available: true`
в конфиге включает передачу задачи в живую сессию Claude Code. Это отдельный шаг,
он требует запуска на вашей машине. Ядро при этом не меняется.
